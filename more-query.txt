This statement means that some existing records in your notes table may have NULL in the important column instead of true or false.

Imagine your notes table looks like this:
id	content	important

The third note has no value for important.

NULL means missing or unknown, not false.
2. Why can these notes not be found?
When you run:
WHERE important = false;


PostgreSQL returns only rows where important is actually false.

It does not return rows where important is NULL.

The same applies when searching for true.
3. What does "set the missing values in the psql console" mean?
It means opening your PostgreSQL terminal (psql) and updating existing records.

For example:
UPDATE notes
SET important = false
WHERE important IS NULL;


Meaning:
- UPDATE notes – modify records in the notes table.
- SET important = false – give missing important values false.
- WHERE important IS NULL – only update records where the value is missing.
4. What does "change the schema so that the column does not allow a null value" mean?
After fixing existing records, prevent future notes from having a missing important value.

In PostgreSQL:
ALTER TABLE notes
ALTER COLUMN important SET NOT NULL;


Meaning: PostgreSQL will reject any new or updated record that tries to leave important as NULL.
5. The difference
Concept	Meaning
NULL	No value / missing
false	A real Boolean value meaning no
true	A real Boolean value meaning yes
NOT NULL	The column must have a value

Your mental model:
1. UPDATE fixes existing missing values.
2. ALTER TABLE ... SET NOT NULL prevents missing values in the future.
One important detail: If your Sequelize model also defines important, make sure it has allowNull: false so your model definition agrees with the database schema.

- "Learning PostgreSQL Basics"

- "Understanding PostgreSQL queries"
