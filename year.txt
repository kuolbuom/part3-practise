1. What is the migrations table?
When your application runs a migration, Umzug records the migration's filename in the migrations table.

For example, after your migration runs, the table might contain:
name
2026211_00_initialize_blogs_and_users.js

This record tells Umzug:
"I have already executed this migration. Don't run it again."

2. What happens if you delete the tables manually?
Imagine you run these SQL commands:
DROP TABLE blogs CASCADE;
DROP TABLE users CASCADE;


Now the blogs and users tables are gone.

However, the migrations table still contains the record saying that your migration has already run.

So, when you restart your application:
1. Umzug checks the migrations table.
2. It sees your migration filename.
3. It assumes the migration has already been executed.
4. It skips the migration.
5. Your blogs and users tables remain missing!
3. How do you solve this?
You must also delete the migration records:
DELETE FROM migrations;


This removes the records but keeps the migrations table itself.

When you restart your application:
1. Umzug checks the migrations table.
2. It finds no executed migration records.
3. It runs your migration again.
4. The users and blogs tables are created again.
5. Umzug records the migration filename.
4. What you did in your exercise
You used:
DROP TABLE IF EXISTS notes CASCADE;
DROP TABLE IF EXISTS users CASCADE;
DROP TABLE IF EXISTS migrations CASCADE;


Then you restarted your application.

That worked because you deleted the migrations table itself, along with the other tables. Umzug recreated the migrations table and ran your migration again.

The important difference:
- DELETE FROM migrations; — removes migration records but keeps the table.
- DROP TABLE migrations; — removes the entire migrations table.
Both approaches can work in this situation.
Remember this mental model
Think of the migrations table as a checklist. It tells Umzug which database changes have already been completed.

If you manually delete the database tables but leave the checklist unchanged, Umzug thinks everything is still done!
